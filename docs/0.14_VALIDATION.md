# 0.14 validation

19 October 2026 (Europe/Zurich).

## Scope and recovery

MiniPaint adds Line, Rectangle and Ellipse, with patterned outline/filled rectangles and ellipses. Shape gestures preview from a snapshot and commit as one Undo step on release; cancellation restores the snapshot. Selection flips, inversion and opaque duplication read original pixels to avoid overlap smearing. Duplicate offsets by eight pixels where possible, reversing direction near an edge and using a smaller offset when neither direction fits eight pixels. Opaque copies can cover underlying pixels, including white; a full-canvas selection has no room for an offset copy. Undo/Redo retains pixel and selection snapshots, with the existing 20-operation bound.

The drawing format remains version 1 (320 × 200 monochrome pixels). PaintStore validates a bounded document on load and rechecks existing disk contents before atomic replacement. Corrupt/newer data is preserved and blocks writes; failed saves keep the edited image/history in memory for PNG export. Retry saved drawing reloads a compatible file after external recovery. No destructive reset or format migration is added.

PaintApplication now owns commands rather than the full view. Canvas, toolbar, shape rasterisation, selection geometry/operations and file persistence have separate source files. Tool shortcuts are Command-1 through Command-7; transforms use Shift-Command-H/V/I/D. Canvas AX labels expose tool/fill/selection state. Native PNG and picture-import dismissal use the shared focus helper. Drawing geometry still requires a pointing device.

Marching ants is optional and off by default. An eight-fps TimelineView animates only the black/white selection border; Reduce Motion keeps it static. Visibility, accessory activity, desktop suspension, scene state, native occlusion and screen sleep gate the timeline. No continuous renderer is present without a selection.

## Automated evidence

Tests cover patterned/outline/filled shapes, symmetry and one-pixel edges, immutable selection transforms and duplicate boundaries, snapshot preview/cancel/commit, selection-aware Undo/Redo, relaunch persistence, scaled/clamped pointer coordinates and every animation gate. Legacy-compatible, future-version, corrupt and failed-write fixtures verify saved-byte preservation and PNG export of unsaved work. A regression test verifies observable completion of selection-only gestures. Populated MiniPaint controls and canvas bounds are checked across all six themes at small Purist/2× logical sizes.

Final release preparation repeats the complete strict lint, Swift tests, release-mode Print Monitor tests, Python CI/release/tap/resource checks and app build on committed source.

## Live development Mac

At saved Aqua 2×:

- Tool shortcuts selected Rectangle, Ellipse, Line and Select. An outline rectangle, filled ellipse and line rendered correctly at the drawn bounds.
- Creating a selection initially left transform menus disabled: gesture completion used unobserved state. The completion snapshot became observable, a regression fixture was added, and the corrected build exposed enabled transforms immediately.
- Flip Horizontally, Flip Vertically, Invert Ink and Duplicate Selection completed through menu/keyboard actions. Undo/Redo worked and all demonstration edits were undone to restore the original drawing.
- Cancelling the native PNG export dialog returned AX focus to the canvas. Opening a demonstration Scrapbook picture showed the reviewed import preview; cancelling retained the drawing and restored canvas focus.
- Marching ants was registered off by default, enabled with a visible selection, and returned to off. This is a functional rendering check rather than a frame-by-frame animation or power measurement.
