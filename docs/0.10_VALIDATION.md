# 0.10 development validation

18 October 2026. This records development evidence, not a published release approval.

## Implemented scope

Chooser stores up to 40 service destinations locally, including service kind and optional port. It validates destinations, ignores stale discovery callbacks, reports browsing/connection state, and opens connections through macOS. Saved entries contain no credentials. Connections menu actions provide a keyboard route; Save Service uses Command-S.

Tiny-screen mode retains 2× as its default and offers a saved 1.5× comparison setting. Purist stays exactly 512 × 384. Common sheet content and form widths now follow the logical desktop width. Impossible instruments is an optional Activity Monitor effect, disabled by default, with a real CPU needle, explicitly decorative particles, a numeric accessible value, and reduced-motion/pause/visibility gates.

## Automated coverage

`make check` passed on the development Mac (192 Swift test executions across debug and release-mode products; no compiler warnings). It runs formatting, Swift tests, release-mode Print Monitor tests, Python CI/release/tap/resource checks, and a development build. New tests cover destination persistence/deduplication/invalid ports, stale discovery callbacks, scale persistence and invalid values, 1.5× geometry, Purist invariants, instrument animation policy, and Chooser action bounds across all six themes at compact sizes.

## Live development preview

On the development Mac, using the Aqua theme:

- Saved and forgot a temporary SSH destination with an explicit port; checked validation feedback and cleared the test fields afterward. No connection was initiated.
- Inspected Chooser field/button accessibility labels and hostname-to-port Tab traversal. Background-window controls appeared later in the Tab sequence; a complete focus-order audit remains open.
- Opened Activity Monitor with the keyboard launcher; paused and resumed sampling with Command-P.
- Switched between 2× and 1.5× through Control Panel and inspected the resulting layout. Restored 2× afterward.
- Enabled Impossible instruments, observed a real CPU sample matching its accessible percentage and visible numeric summary, then restored the effect to off.

## Remaining evidence

Development-monitor screenshots do not establish Wokyis legibility. Compare the presets physically before changing the default. VoiceOver labels and bounds are covered in part, but a spoken end-to-end VoiceOver pass and complete keyboard workflow matrix are still required. Lifecycle policy tests do not substitute for physical sleep/wake testing.

The earlier Mini display-change and display-sleep results, and the unresolved full-system-sleep check while CI/recorder assertions are active, remain documented in [Wokyis validation](WOKYIS_VALIDATION.md).
