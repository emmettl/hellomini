# 0.12 validation

19 October 2026 (Europe/Zurich).

## Scope and recovery

Scrapbook adds up to 100 named collections, favourites and title/date sorting. Filters compose with search and archive state. Removing a collection retains every scrap. Version-1 indexes remain readable; the first version-2 save preserves the original index as `scrapbook.v1.json`, alongside the normal previous-index backup. Back up the whole directory before downgrading; old app versions cannot read version 2, and the retained version-1 index does not contain subsequent edits. Portable archives accept versions 1 and 2. Full backups retain empty collections; visible-selection exports include only referenced collection names.

Calculator saves the latest 50 successful expressions in versioned local preferences. Reuse fills the expression/result without re-executing. Bad/future history is preserved and disables history writes until explicit reset, which retains a previous encoded copy. The explicit Scrapbook handoff uses the last calculated source/result, even if the input has since been edited. Other Calculator panes remain session inputs.

Depth behind glass is optional and off by default. Three nested perspective cubes and bounded stippling use theme ink/paper at 12 fps. Reduce Motion gives a static scene; hidden, obscured, inactive and sleeping desktops pause the timeline. This is decorative rather than a calculation or machine-status display.

Calculator model, history and pane implementations and the Scrapbook editor now have separate source files. Shared sheets have native responder fallback; Scrapbook explicitly restores search after edit, organisation and import-preview dismissal, with cancellation on accessory deactivation/disappearance. Finder retains its selected-item restoration.

## Automated and live evidence

The initial full `make check` passed 201 Swift test executions, strict format lint, release-mode Print Monitor tests, Python CI/release/tap/resource checks and the development build. Final release preparation reruns these checks on the committed source. New fixtures cover the exact legacy Scrapbook JSON shape, retained migration bytes, future-version refusal, portable collections/favourites, empty groups, collection removal, combined search/filtering, bounded persistent history, reuse/reset and perspective/lifecycle bounds.

Live development-Mac checks at saved Aqua 2× confirmed:

- Calculator evaluated `12 * 12`, showed 144, retained its history after relaunch and offered expression reuse.
- Send result created a Scrapbook note containing `12 * 12 = 144` and activated Scrapbook.
- Organisation sheet created and removed a collection while retaining scraps; favourite changes persisted.
- The editor selected its title initially. Live testing exposed the generic responder fallback returning to the native window rather than the search field; explicit, delayed Scrapbook focus restoration fixed this, and Escape subsequently returned AX focus to Search scrapbook.
- Glass was disabled by default, then enabled through its registered Playfulness switch and visibly rendered its themed nested cubes. The preference was returned to off.
- Compact Calculator and collection/editor sheets use scrolling to keep actions reachable. These checks establish functional layout, not a new physical reading-distance comparison.
