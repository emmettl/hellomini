# 0.15 validation

19 October 2026 (Europe/Zurich). Implementation candidate; not a published release.

## Scope

Key Caps highlights currently held physical US-position keys, Space and modifiers. Its local monitor returns application events unchanged; other applications are not monitored. Accessory activity/visibility, desktop suspension, scene activity and native key-window state gate input. Losing the native key window or deactivating/dismantling the accessory clears held keys. Caps Lock changes letters only and combines with Shift; reference labels do not translate alternative keyboard layouts. The compact view scrolls as one document rather than compressing the keyboard behind fixed status rows.

World Clock search receives initial focus and Escape dismisses Add. World Clock, desktop presets/backups, Print Monitor (including nested history/token dialogs) and Communications use the shared event-driven dismissal helper. The fallback destinations are Add, the desktop launcher/dock, Projects, history branch, project path and Station Setup. Existing Finder/Scrapbook/Paint focus paths remain in place.

Preset storage is separate from the sheet, retries externally repaired saved preferences and preserves unexpected preference types. Each replacement revalidates existing preferences and retains the previous compatible document at `desktop.presets.v1.previous`; late unreadable/newer data blocks replacement. Desktop layout decoding is bounded at 500 KB. Scrapbook checks existing index size before save-time rereading, before touching backup/image data. Paint's bounded load/save and in-memory failed-save recovery were reviewed without a format change. Desktop surface rendering is separate from window/menu coordination.

The [keyboard matrix](KEYBOARD_ACCESS.md) records source-reviewed routes and pointer-dependent workflows. It distinguishes source review, targeted live checks and spoken/physical coverage.
